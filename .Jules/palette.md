## 2026-04-27 - Enhanced Focus Management for Smooth Scrolling
**Learning:** For single-page applications with smooth scrolling, visual navigation alone is insufficient for accessibility. Without programmatically shifting focus to the target section (using `tabindex="-1"` and `.focus()`), keyboard and screen reader users remain trapped at the top of the page, even as the viewport moves. Additionally, using `removeAttribute('aria-current')` rather than `setAttribute('aria-current', 'false')` provides a cleaner semantic state for assistive technologies.
**Action:** Always synchronize the accessibility focus with visual scrolling by implementing a delayed focus shift (allowing for animation duration) and strictly managing the presence/absence of binary state attributes like `aria-current`.
